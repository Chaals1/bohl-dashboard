How this works

The dashboard is a single web page with no server behind it, so this form can't add the city or the person by itself. What it does do is write out the exact instruction that makes the change — you copy it, and it gets run once to update the dashboard.

  1. Fill in the form below.
  2. Hit the button — a command appears.
  3. Click Copy and send it to Skip (or run it, if you're set up to).
  4. For a new franchisee whose sheet should update on its own, there's one extra step on our side to connect their Google Sheet. The form will remind you.

Nothing on this page changes the live dashboard. It only writes out the instruction.
